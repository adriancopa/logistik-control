# Logistik Control (web)

Aplicación de gestión logística: pedidos, planificación de itinerarios, seguimiento en vivo, combustible y mantenimiento.
Los datos se sincronizan con Google Sheets (Apps Script) y con la app Android.

Esta página es solo la aplicación; **no contiene datos ni claves**. Para entrar se necesita el enlace de acceso que entrega el administrador.
